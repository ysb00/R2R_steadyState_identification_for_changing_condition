### 4. ② 공통 평가 모듈 — `code/03_baselines/evaluation.py`

제안 모델과 비교군 전부가 이 파일 하나를 import 한다 (동일 후단 · 동일 채점 = 공정성).

**라벨 누출 차단**: `Trigger 4` 를 읽는 코드는 이 파일의 `_labels()` 한 곳뿐이다.
방법 스크립트는 `merged_data.csv` 를 읽을 때 `Trigger 4` 를 `usecols` 에 넣지 않으며, 라벨 배열을 변수로 들지 않는다.

트랙 A 후단: 표현 → (표준화 → 2-군집 GMM) 학습 fold 적합 → |e 평균| 작은 군집 = steady → 검증 fold 판정.
**표준화를 GMM 앞에 넣었다** — std(kg)와 기울기(kg/s)처럼 축마다 단위·분산이 다르면 분산이 큰 축이 군집을 지배하기 때문이며,
모든 방법에 동일하게 적용된다 (계획 문서에는 없던 추가 단계).

지표: 오염률·보존률·F1·AUROC·AUPRC 를 pooled 와 run 평균 두 가지로, steady 진입 시점 오차는
부호 포함 평균(bias)·절대 평균(MAE)·표준편차와 "진입을 전혀 판정하지 못한 run 수"를 함께 기록한다.

플롯: 논문 스타일(grid, 영어 축·범례, PNG 300 dpi + PDF, 글꼴 크기 통일)을 이 파일에 모아 두었다.
방법별 고정 색은 검증된 categorical 색이 8개뿐이라 **색은 계열 단위로 고정하고 계열 안에서는 marker·선종류로 구분**한다
(방법 10개 > 8). 비교 그림을 실제로 만들 때 재검토.
결과 파일은 같은 이름이 이미 있으면 저장을 거부한다 (덮어쓰기 금지).

### 5. ③ 통계 기준선 2종 — `code/03_baselines/01_stat_ssd.py`

주 실험(장력 5-fold)만 수행. 결과: `outputs/03_baselines/01_stat_ssd/`

**R-test** (Cao & Rhinehart 1995). 식과 기본값은 Rhinehart 본인의 튜토리얼
"Automated Steady and Transient State Identification in Noisy Processes" (r3eda, 2019-05-08) pp.12-16 에서 확인했다:
λ1=0.2, λ2=λ3=0.1, 필터값 0 초기화, R>2.5 → non-steady, R<0.9 → steady, 사이값은 직전 판정 유지.
학습 없이 원 논문 임계값을 그대로 썼다. non-steady 점수는 R 통계량 자체.

**이동창 std + 기울기**. 뒤쪽(causal) 이동창의 표준편차와 최소제곱 기울기를 2차원 표현으로 쓰고 트랙 A 후단에 넣었다.
창 길이는 고정 `WINDOW=64` samples(약 7.0 s)와 속도별 `W(V)=WINDOW×SPEED_REF/V` (`SPEED_REF=125`) 두 변형.
속도별 조정 근거는 steady 구간 주기 성분의 주파수가 속도에 비례한다는 관찰이며, 필름 이동 거리 기준 창과 같은 형태(∝1/V)다.
창이 다 차기 전 앞 구간은 첫 완전창 값으로 채워, 창 길이가 달라도 채점 대상 시점 수가 같게 했다.

### 6. 결과 (주 실험 5-fold 평균, seed 5회)

| 방법 | 오염률 (pooled / run평균) | 보존률 (pooled / run평균) | AUROC | AUPRC | F1 | 진입 오차 bias / MAE (s) | 진입 미검출 run |
|---|---|---|---|---|---|---|---|
| R-test (9 Hz, 원 논문 임계값) | 1.000 / 1.000 | 0.000 / 0.000 | 0.698 | 0.355 | 0.149 | −23.4 / 23.4 | 207 / 210 |
| R-test (1/10 다운샘플링) | 0.021 / 0.244 | 0.174 / 0.171 | **0.901** | 0.579 | 0.167 | +27.6 / 43.8 | 110 / 210 |
| MovStd-Slope (고정 창) | 0.032 / 0.030 | 0.962 / 0.963 | 0.878 | 0.702 | 0.625 | −10.2 / 10.8 | 0 |
| MovStd-Slope (속도별 창) | 0.032 / 0.030 | 0.956 / 0.957 | 0.895 | 0.684 | 0.607 | −11.2 / 11.7 | 0 |

**R-test 를 원 샘플링(9 Hz)에서 쓰면 무너진다.** 전체 시점의 88%에서 R>2.5 라 거의 모든 시점을 non-steady 로 선언하고,
R<0.9 인 시점은 0.0% 다 (R 중앙값 3.77, 정상상태 기대값은 ≈1). 210 run 중 207 run 에서 steady 진입을 한 번도 판정하지 못했다.

원인은 **자기상관**이다. R-test 는 정상상태 잡음이 백색(독립)이라고 전제하고, 튜토리얼은 그 전제를
"샘플링 간격 선택으로 확보한다"고 명시한다. 9 Hz 에서는 연속 차분 기반 분모 δ²_f 가 과소평가되어 R 이 부풀려진다.
즉 **원 논문이 전제한 운전 조건 밖에서 쓰고 있던 상태**였다.

그래서 원 논문 전제를 맞추기 위해 **1/10 다운샘플링 후 다시 돌렸다** (`RTEST_DECIMATE=10`; steady 구간 자기상관이
lag10 에서 0.16 까지 떨어지는 것이 근거). 판정은 직전 다운샘플 시점의 값을 끌어와 원래 시점으로 되돌렸고,
채점은 모든 방법과 같은 9 Hz 시점에서 한다. 결과는 크게 달라졌다:

- R 중앙값 3.77 → **1.43** (이상값 ≈1 에 훨씬 가깝다), R>2.5 비율 0.881 → 0.167
- AUROC 0.698 → **0.901 — 통계 기준선 중 가장 높다**
- 그러나 보존률은 0.000 → **0.174** 에 그치고, 110 run 은 여전히 진입을 판정하지 못한다

즉 **R 통계량은 조건을 맞춰주면 매우 잘 분리하는데(AUROC 0.901), 고정 임계값 2.5/0.9 가 이 데이터에 맞지 않는다.**
깨진 것은 통계량이 아니라 임계값 보정이고, 이는 `research_plan.md` 2절의 연구 동기
("통계 기반 SSI 는 조건별 임계값 재튜닝이 필요하다")를 본 데이터에서 직접 보여주는 결과다.

남은 R 부풀림의 원인으로 두 가지를 본다. ① 다운샘플링 후에도 잔여 자기상관이 남는다
(run 전체 기준 lag1 0.92 → 0.54; 다만 이 수치는 과도구간을 포함한 값이라 `research_plan.md` 1.2절의
steady 구간 전용 수치 0.85 와 직접 비교할 수 없다). ② 튜토리얼이 명시한 또 다른 실패 조건인
**주기적 배경 추세**가 본 데이터의 steady 구간에 존재한다 (속도 비례 주기 성분).
한편 다운샘플링을 더 키우기는 어렵다 — run 길이가 약 140 s 뿐인데 R-test 는 초기화에만 약 35 샘플(3.5/λ)이 필요해,
`RTEST_DECIMATE=10` 에서 이미 초기화 구간이 run 의 약 27% 를 차지한다. 샘플링 간격과 run 길이가 서로 충돌한다.

**run 평균 오염률(0.244)이 pooled(0.021)보다 10배 넘게 크다.** steady 로 판정한 시점이 run 당 몇 개뿐이라
run 단위 분모가 극히 작아 생기는 차이다. 두 집계를 모두 기록하기로 한 결정이 여기서 실제로 쓰였다.

**창 길이 고정 vs 속도별 조정은 이 단순 기준선에서는 사실상 차이가 없다** (오염률 동일, AUROC 0.878 → 0.895,
보존률 0.962 → 0.956). D1 가설의 본격적 검증은 창 기반 표현학습 방법(TNC, TS-TCC, SimMTM)에서 해야 한다.

**조건별 구조**: 오염률이 낮은 속도(50–100 mm/s)에 몰린다. 특히 장력 5–7 kg fold 에서 V=50 열이 0.12–0.16 으로 뚜렷하다.

**진입 시점 오차가 변별력 있는 지표다.** 편향의 방향이 방법마다 갈린다 —
MovStd-Slope 는 전문가보다 10–11 s **빨리**, 다운샘플링 R-test 는 28 s **늦게** steady 를 선언한다.
steady 가 86% 라 오염률·보존률만 보면 "거의 전부 steady" 라는 자명한 해도 오염률 3–5% / 보존률 99.9% 가 나온다
(공통 평가 모듈 smoke test 로 확인). 비교군 표를 읽을 때 이 점을 전제해야 한다.

`_progress_fold.csv`, `_progress_run.csv`, `_loss.csv`, `checkpoints/*.pt`(gitignore), `run.log`.

3.2 근처에서 평평하고(= 사실상 학습 전 난수 초기화 인코더), fold 1·2·5 는 끝에서야 떨어지기 시작해 여전히 하강 중이다.
25회 중 **11회는 손실이 0.3 도 떨어지지 않았다.**

이것이 seed 편차가 거대한 이유다 — 보존률이 fold 3 에서 0.780 ± 0.304, fold 5 에서 0.606 ± 0.347,
전체 범위 0.222–0.924 다. 어떤 seed 가 600 반복 안에 정체 구간을 벗어나느냐가 결과를 결정한다.

**그리고 학습이 덜 된 쪽이 모든 지표에서 더 좋다.**

| 구분 | n | 보존률 | AUROC | AUPRC | 오염률 |
|---|---|---|---|---|---|
| 손실 거의 안 떨어짐 (drop < 0.3) | 11 | 0.774 | 0.884 | 0.438 | 0.001 |
| 손실 떨어짐 | 14 | 0.655 | 0.822 | 0.270 | 0.002 |

최종 손실과 AUPRC 의 상관이 **+0.61**, 보존률과는 +0.37 이다. 즉 TS2Vec 의 대조 목적함수를 더 많이 최적화할수록
steady/non-steady 분리는 나빠진다. 난수 초기화 인코더는 입력의 무작위 사영이라 **진폭 정보**를 보존하는데,
학습이 진행되면 증강 불변 특징을 배우면서 그 진폭을 버리는 것으로 보인다 —
`research_plan.md` 3.1 의 D2("scaling 은 오차 진폭(구분 정보)을 변경한다")와 방향이 맞는 관찰이다.
다만 표본이 25회뿐이고 수렴 전 상태에서 본 것이라 **아직 주장이 아니라 관찰**이다.

부수적으로 TS2Vec 의 오염률은 0.002 로 전체 최저지만 AUPRC 는 0.344 로 전체 최저다.
steady 로 인정하는 양 자체가 적어서 생기는 조합이고, 오염률만 보고 판단하면 안 된다는 뜻이다.
