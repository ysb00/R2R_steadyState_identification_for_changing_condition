  평가는 전 방법 동일한 트랙 A 후단(학습 fold 표준화 + 2-군집 GMM → |e 평균| 작은 군집 = steady).

### 0.3.1 `n_runs_*` 열을 함께 봐야 하는 이유

**지표마다 계산 가능한 run 수가 다르다** (검증 fold 42 run 기준):

| 지표 | 유효 run | 이유 |
|---|---|---|
| 오염률·보존률 | 42.0 | 전 run |
| `precision_nonsteady` | 32.0~42.0 | non-steady 판정이 0인 run 은 분모가 없다 |
| **AUROC·AUPRC·F1(ns)** | **36.8** | **steady 또는 non-steady 가 한쪽도 없는 run 약 5개는 빈칸** |
| `R-test` 오염률 | **3.4 / 42** | steady 판정이 거의 없어 분모가 사라진다 |
| `R-test-decimated` 오염률 | **18.8 / 42** | 같은 이유 |

즉 **AUROC·AUPRC 의 run 평균은 42 run 이 아니라 약 37 run 에서만 계산된 값**이다.
그리고 `R-test` 계열의 run 평균 오염률이 pooled 와 12배 차이 나는 이유가 여기 있다
(0.244 vs 0.021) — **42 run 중 3.4개에서만 계산됐다.**

`f1_st`(steady 쪽 F1)는 **혼동행렬로 복원**되므로 전 방법에 값이 있다
(`evaluation.derive_precision_recall`, 무작위 10만 건 검증 실패 0).

### 0.4 학습량이 방법마다 다르다 — **As-published 방침의 알려진 한계**

각 저장소 기본값을 그대로 쓰기로 한 결과다(`research_experiments_plan.md` §3). 데이터 통과 횟수:

| 방법 | 학습량 설정 | 데이터 통과 |
|---|---|---|
| CoST W144 / W160 / W256 / W306 / W512 | 600 iter | **3.17 / 3.57 / 5.71 / 7.14 / 14.29** |
| SimMTM | pretrain 10 epoch | 9.99 |
| TS2Vec / SoftCLT 3변형 | 600 iter | 28.57 |
| TS-TCC | 40 epoch | 38.07 |
| 통계 SSD 8종 / MOMENT | 학습 없음 | — |

**통과 횟수와 AUPRC 가 거의 역순이다** — 가장 덜 학습한 CoST-W144 가 1위다. 즉 **방법 간 성능차에
학습량 효과가 섞여 있다.** 동일 epoch 예산 정렬은 `hyperparameters.md` §13.2 의 후일 작업이다.

### 0.5 퇴화(degenerate) 건수 — `n_degenerate` 컬럼

GMM 이 "steady vs non-steady" 가 아니라 **"이상치 190개 vs 나머지 전부"** 로 쪼개 AUROC 가 정확히
0.500, 보존률이 정확히 1.000 이 된 건수다.

| 방법 | 퇴화 | fold | seed |
|---|---|---|---|
| TS-TCC | **4 / 25** | 2, 3, 4, 5 | 2 |
| SimMTM | **2 / 25** | 2, 3 | 2 |
| 나머지 21종 | 0 | — | — |

원인은 **진폭 이상 run `T3_R2_V200`** (e 범위 −1.01~+2.87)이다. 그 run 의 `fold_tension = 1` 이므로
**fold 2·3·4·5 에서만 학습셋에 들어가고**, 두 방법의 퇴화 fold 가 정확히 그 집합이다.
표현 차원이 2,560(TS-TCC)과 1,024(SimMTM)로 2.5배 다른데 같은 seed·fold 에서 터졌으므로
**원인은 차원이 아니라 그 run** 이다. 상세는 `hyperparameters.md` §11 문제 11.

**표의 값은 퇴화를 포함한 전체 평균이다**(연구자 결정). 퇴화 제외값은 TS-TCC AUROC 0.906 / AUPRC 0.328,
SimMTM 0.922 / 0.412 이다. 전체 평균을 싣고 각주로 병기한다 — 퇴화 제외값만 싣는 것은 선택적 보고다.

## 1. 통계 SSD — R-test 4종

4종은 **2×2 설계**다: 샘플링(원 9 Hz / 1-10 다운샘플) × 임계값(원 논문 고정 / 학습 fold 보정).

| # | 방법 | 샘플링 | 임계값 |
|---|---|---|---|
| 1 | `R-test` | 9 Hz (원본) | 원 논문 2.5 / 0.9 |
| 2 | `R-test-decimated` | 1/10 다운샘플 | 원 논문 2.5 / 0.9 |
| 3 | `R-test-calibrated` | 9 Hz (원본) | **학습 fold GMM** |
| 4 | `R-test-decimated-calibrated` | 1/10 다운샘플 | **학습 fold GMM** |

### 1.1 `R-test` — 원 논문 그대로

**무엇인가**: Cao & Rhinehart(1995)의 분산비 R = (2−λ1)·ν²_f / δ²_f 를 EWMA 로 온라인 갱신하고,
`R > 2.5 → non-steady`, `R < 0.9 → steady`, 사이는 직전 판정 유지(히스테리시스)로 판정한다.
식·기본값 출처는 Rhinehart r3eda 튜토리얼(2019) pp.12-16. **학습 없음**, 결정론적이라 seed 1회.

**왜 돌렸나**: 공정 분야에서 가장 널리 쓰이는 통계 SSI 기준선이다.

**결과와 해석**: **무너진다.** 전체 시점의 88%에서 R > 2.5 라 거의 모든 시점을 non-steady 로 선언하고
`R < 0.9` 인 시점이 **0.0%** 다. 보존률 0.000, 210 run 중 207 run 에서 steady 진입을 한 번도 판정하지 못했다.

**원인**: 자기상관이다. R-test 는 정상상태 잡음이 백색이라고 전제하고 튜토리얼은 그 전제를
"샘플링 간격 선택으로 확보한다" 고 명시하는데, 9 Hz 에서 steady 구간 lag1 자기상관이 **0.85** 다.
즉 **원 논문이 전제한 운전 조건 밖에서 쓰고 있던 상태**다.

**주의**: 이 행을 "R-test 는 쓸 수 없다" 로 읽으면 안 된다. 2·3·4 와 함께 봐야 한다.

### 1.2 `R-test-decimated` — 원 논문 전제를 맞춘 것

**무엇인가**: e 를 10 샘플마다 하나씩 뽑아(`e[::10]`) R 을 계산·판정하고, 판정을 원래 시점으로
되돌린다(causal forward-fill). 채점은 모든 방법과 같은 9 Hz 시점에서 한다.

**왜 돌렸나**: 원 논문 전제(잡음 무상관)를 충족시키기 위해서다. lag10 에서 자기상관이 0.16 까지
떨어지는 것이 근거다. `RTEST_DECIMATE = 10` 은 **[임의]** 값이다.

**결과**: R 중앙값 3.77 → **1.43**(이상값 ≈ 1 에 근접), AUROC 0.698 → **0.901**.
그러나 보존률은 **0.174** 에 그치고 110 run 이 여전히 진입을 판정하지 못한다.

**해석**: **R 통계량은 조건을 맞춰주면 잘 분리하는데 고정 임계값 2.5/0.9 가 이 데이터에 안 맞는다.**
깨진 것은 통계량이 아니라 임계값 보정이다.

**주의**: run 길이와 충돌한다 — R-test 는 초기화에만 약 35 샘플(3.5/λ)이 필요한데, 다운샘플 10 에서
이미 초기화 구간이 run 의 **27%** 다. 더 큰 배수는 쓸 수 없다.

### 1.3 `R-test-calibrated` / 1.4 `R-test-decimated-calibrated` — 임계값 보정판

**무엇인가**: 원 논문 고정 임계값을 버리고, **R 1차원을 '표현' 으로 보아 다른 모든 비교군과 동일한
트랙 A 후단**(학습 fold 표준화 + 2-군집 GMM → |e 평균| 작은 군집 = steady)에 넣는다.

**왜 돌렸나**: 1.2 의 해석("깨진 것은 임계값") 을 검증하고, 보정 없이 표를 실으면 "비교군을 불리한
설정으로 돌렸다" 가 되는 것을 막기 위해서다. 그리고 연구 동기(조건별 임계값 재튜닝 필요)를 정량화한다.

**방식 선택**: 분위수 쌍으로 보정하면 **새 임의값이 2개** 늘어난다. 트랙 A 후단을 재사용하면
**새 임의값이 0개**이고 MovStd-Slope 와 같은 구조가 된다. 후자를 택했다(연구자 결정).

**원 샘플링·다운샘플링 둘 다 보정한 이유**: 한쪽만 보정하면 그 선택이 새 임의값이 된다.
2×2 로 두면 **샘플링 효과와 임계값 효과가 분리된다** — 샘플링은 **분리력**(AUROC 0.69 → 0.91,
보정 여부와 무관)을, 보정은 **작동점**(보존률 0.000 → 0.972 / 0.174 → 0.887, 미검출 run 전부 0)을 바꾼다.

**주의 2건**:
- 보정판은 원 논문의 **2-임계값 히스테리시스를 쓰지 않는다.** 트랙 A 후단은 사후확률 ≥ 0.5 의 단일
  임계이므로, 바뀐 것이 '임계값' 뿐이 아니라 **'임계 규칙'** 이기도 하다.
- **점수도 바뀐다**(R 통계량 → GMM 사후확률). 1차원 GMM 사후확률은 R 의 단조함수가 아닐 수 있어
  AUROC 가 0.901 → 0.910 으로 움직인 것은 "임계값만 바꿨다" 로 설명되지 않는다.

## 2. 통계 SSD — 이동창 std + 기울기 4종

**원 논문이 없는 자작 단순 기준선**이다. "조용하고(변동이 작고) 흐르지 않으면(추세가 없으면)
정상상태" 라는 정의를 그대로 옮겼다. `(std, |기울기|)` 2차원을 표현으로 보고 트랙 A 후단에 넣는다
— 즉 **"2차원 표현을 만드는 인코더"** 로 취급된다. 임계값을 손으로 정하지 않는 이유는 그렇게 하면
라벨을 보게 되거나 조건마다 다시 맞춰야 하기 때문이다(`outputs_guide.md` §10.3.3).

4종은 **2×2**: 창 길이(임의 64 / 규칙 1b 144) × 창 방식(고정 / 속도별).

| # | 방법 | 창 길이 | 근거 |
|---|---|---|---|
| 5 | `MovStd-Slope-fixed` | 64 고정 | **[임의]** |
| 6 | `MovStd-Slope-speed` | `round(64 × 125 / V)` = 160~40 | **[임의]** 기준값 64·125 |
| 7 | `MovStd-Slope-fixed-rule1b` | **144 고정** | **규칙 1b** (회전 외란 1주기) |
| 8 | `MovStd-Slope-speed-rule1b` | `⌈fs·C/V⌉` = 144~36 | **규칙 1b**, 속도별 |

**왜 4종인가**: 5·6 은 임의값 64 로 돌린 초기 변형이고, 7·8 은 창 길이를 회전 외란 주기에서 유도한
규칙 1b 로 교체한 것이다. **5·6 은 지우지 않고 창 길이 효과의 대조군으로 유지한다** —
`periodic_disturbance.md` §7.2 의 창 하한 근거 그림이 그 데이터를 쓴다.

**결과 — 규칙 1b 적용 효과가 지표별로 엇갈린다**:

| | AUROC | AUPRC | 보존률 | 진입 bias |
|---|---|---|---|---|
| `-fixed` (64) | 0.884 | **0.718** | **0.978** | −10.9 s |
| `-fixed-rule1b` (144) | **0.957** | 0.608 | 0.905 | **+2.5 s** |

창을 늘리니 **분리력(AUROC)과 진입 정확도는 크게 개선**되고 **AUPRC·보존률은 나빠졌다.**
`hyperparameters.md` §12 가 예상한 "개선될 수도, 안 될 수도" 가 지표별로 갈리는 형태로 나왔다.

**주목할 점**: `-fixed-rule1b` 의 **진입 bias +2.5 s 는 23종 중 최소**다(CoST −3.2 s 보다 작다).
그리고 `-fixed` 의 **AUPRC 0.718 은 CoST 계열을 제외하면 전체 1위**다 — 2차원 기준선이
320~2,560차원 표현학습 7종을 전부 이긴다.

**창 길이 고정 vs 속도별은 사실상 차이가 없다**(5↔6, 7↔8). 속도별 창은 이미 모든 속도에서
1주기 이상을 담는데도 개선이 없었다.

## 3. 대조학습 — TS2Vec

### 9. `TS2Vec`

**무엇인가**: 계층적 대조학습(Yue et al., AAAI 2022). 시점 단위 표현을 직접 내놓으므로 창 변환이
필요 없다 — `max_train_length = 3000 > 1300` 이라 **run 전체를 한 번에 본다.**

**설정**: 저장소 `train.py` argparse 기본값 전부 (batch 8, lr 1e-3, repr 320, iters 600).
**이 방법만 As-published 가 완전히 성립한다**(CoST·SoftCLT 는 불가, 아래 참조).

**결과**: AUPRC 0.344. 오염률 0.002 로 전체 최저이지만 보존률이 0.707 이다 —
**steady 로 인정하는 양 자체가 적어서** 생기는 조합이고, 오염률만 보고 판단하면 안 된다는 예시다.

**주의 — 두 가지 알려진 문제**:
1. **600 iter 에서 수렴하지 않는다.** 25회 중 **11회는 손실이 0.3 도 떨어지지 않았다**(= 사실상
   난수 초기화 인코더). fold 3·4 는 28 epoch 내내 평평하다.
2. **학습이 덜 된 쪽이 모든 지표에서 더 좋다.** 최종 손실 ↔ AUPRC 상관 **+0.61**.

| 구분 | n | 보존률 | AUROC | AUPRC |
|---|---|---|---|---|
| 손실 거의 안 떨어짐 (drop < 0.3) | 11 | 0.774 | 0.884 | **0.438** |
| 손실 떨어짐 | 14 | 0.655 | 0.822 | **0.270** |

이것이 **seed 편차가 거대한 이유**다 — 보존률 fold·seed 표준편차 **0.267**(23종 중 최대급).
난수 초기화 인코더는 입력의 무작위 사영이라 **진폭 정보를 보존**하는데, 학습이 진행되면 증강 불변
특징을 배우면서 그 진폭을 버리는 것으로 보인다. `research_plan.md` 3.1 **D2** 와 방향이 맞는
관찰이지만, 표본 25회에 수렴 전 상태라 **아직 주장이 아니라 관찰**이다.

## 4. 대조학습 — CoST 5창

### 10~14. `CoST-W144` / `W160` / `W256` / `W306` / `W512`

**무엇인가**: 추세·계절 성분을 분리해 각각 대조학습하는 방법(Woo et al., ICLR 2022).
표현은 `cat([trend(160), season(160)])` = 320차원이다.

**왜 5창인가 — 창을 고르는 것이 선택이 아니다**: 저장소 기본값 `max_train_length = 3000` 은
**본 데이터(길이 1300)에서 쓸 수 없다.** 분할이 일어나지 않고(`1300 // 3000 = 0`),
`BandedFourierLayer(length=3000)` 가 길이 1300 입력을 받아 **주파수 빈 651 vs 1501 차원 불일치로
크래시**한다. 따라서 `max_train_length ≤ 1300` 인 값을 **반드시 우리가 골라야 한다.**
→ **As-published 가 구조적으로 불가능한 방법이다.**

**본문 창은 144** — 규칙 1b 유도값이다. 나머지 4종은 **창 길이 민감도용**이다.

**결과 — 창이 길어질수록 모든 지표가 단조 악화한다**:

| W | 통과 횟수 | AUPRC | 보존률 | 진입 bias |
|---|---|---|---|---|
| **144** | 3.17 | **0.832** | 0.991 | −3.2 s |
| 160 | 3.57 | 0.814 | 0.987 | −1.7 s |
| 256 | 5.71 | 0.533 | 0.926 | +8.3 s |
| 306 | 7.14 | 0.428 | 0.885 | +13.6 s |
| 512 | 14.29 | **0.231** | 0.707 | +35.5 s |

**CoST-W144 가 23종 전체 1위**다(ablation 제외). 오염률 0.005 / 보존률 0.991 / F1(ns) 0.902 /
진입 MAE 5.8 s 로 종합 지표가 2위권과 큰 격차다.

**주의 — 이 5행은 창 효과만 보여주는 것이 아니다**: `max_train_length = W` 가 run 을 `1300//W`
조각으로 쪼개므로 **같은 600 iter 에서 창별 학습량이 다르다**(통과 3.17 ~ 14.29회, 4.5배).
**통과 횟수와 AUPRC 가 완벽한 역순**이라 창 효과와 학습량 효과를 분리할 수 없다
(`hyperparameters.md` §11 문제 9). 세 결론이 불확정이다 — ① CoST 1위가 설계인지 미학습인지
② 창이 길면 나빠지는 것이 창 효과인지 학습량 효과인지 ③ **seed 안정성이 TS2Vec 의 1000배**
(σ 0.010 vs 0.267)인 것이 설계인지 학습 진행도인지.

**또 하나의 주의**: 저장된 `iters_per_epoch` 컬럼은 **W=144 를 제외하고 틀렸다**
(`n_iters // n_epochs` 로 계산해 과대평가). 쓰지 말 것.

## 5. 대조학습 — SoftCLT 3변형

**무엇인가**: TS2Vec 의 hard 양성/음성 라벨을 연속 가중치(soft label)로 바꾼 방법(Lee et al., ICLR 2024).
인스턴스 축은 run 간 DTW 거리로, 시간 축은 시점 간 시간 차로 가중치를 만든다.

**왜 3변형인가 — As-published 가 불가능하다**: 저장소 기본값이 `tau_inst = 0, tau_temp = 0` 이고
코드가 `soft_instance = (tau_inst > 0)` 이므로 **기본값에서는 soft 요소가 전부 꺼져 평범한 TS2Vec 과
같아진다.** 그리고 tau 가 바뀌면 목적함수 자체가 바뀌므로 **손실값으로 tau 를 고를 수 없다.**

| # | 방법 | `tau_inst` | `tau_temp` | 반경 | 출처 |
|---|---|---|---|---|---|
| 15 | `SoftCLT-ref` | 5.0 | 1.0 | 1.1 샘플 | **[저자표]** UCR 128개 튜닝표 중앙값 |
| 16 | `SoftCLT-fs` | fold별 수치해 (158~232) | 0.034 | 32 샘플 | **[데이터]** — 반경 = 임의창 64 의 절반 |
| 17 | `SoftCLT-fs-rule1b` | fold별 수치해 | **0.0153** | **72 샘플** | **[데이터]** — 반경 = 규칙 1b 창 144 의 절반 |

**저자 표 격자가 본 데이터에서 퇴화한다**: SoftCLT 는 DTW 거리를 MinMax 로 [0,1] 정규화하는데,
**진폭 이상 run 2개**(`T3_R2_V200`, `T4_R6_V150`)가 최대값을 중앙값의 19.8배까지 올려 나머지 99%가
[0, 0.05] 로 짓눌린다. 그 결과 앵커당 유효 양성 수 n_eff 가 tau_inst=5 에서 **75.5**(학습 167개 중)로
**음성이 사실상 사라진다.** 비퇴화가 되려면 tau_inst 가 158~232 여야 한다.
→ `-fs` 변형은 **n_eff 중앙값을 5.0 으로 맞추는 tau 를 fold 마다 수치해로 구한다.**
고정하는 것은 tau 가 아니라 **'이웃으로 보는 run 수'** 다.

**결과 — 시간 축 soft label 이 본 데이터에서 거의 작동하지 않는다**:

| 변형 | `tau_temp` | 반경 | AUPRC | 보존률 |
|---|---|---|---|---|
| `-fs` | 0.034 | 32 | 0.244 | 0.639 |
| `-fs-rule1b` | 0.0153 | 72 | 0.269 | 0.648 |
| `-ref` | 1.000 | 1.1 | 0.273 | 0.624 |

반경을 **2.25배** 늘려도 전 지표가 ±0.025 안에서 움직이고, `tau_temp` 를 0.015~1.0 (**65배**) 범위로
바꿔도 AUPRC 가 0.244~0.273 에 머문다. 반경 1.1 샘플(`-ref`)은 사실상 hard label 이라 TS2Vec 과
같은데도 차이가 없다. **그리고 TS2Vec 자체가 AUPRC 0.344 로 세 변형보다 높다** —
soft label 이 이 데이터에서는 오히려 해롭다.

**부수 효과**: `-fs-rule1b` 실행으로 **임의값 64 의 마지막 전파 경로가 닫혔다**
(`hyperparameters.md` §10 #6·#11 해소).

**주의**: seed 편차가 크다 — 보존률 표준편차 0.234~0.282 로 TS2Vec(0.267)과 같은 수준이다.

## 6. 대조학습 — TS-TCC

### 18. `TS-TCC`

**무엇인가**: weak/strong 두 증강을 걸고 ① Temporal Contrasting(한 view 의 과거로 다른 view 의
미래를 맞춤) ② Contextual Contrasting(두 view 의 문맥 벡터를 NT-Xent 로 끌어당김)을 함께 학습
(Eldele et al., IJCAI 2021). 손실 = (TC 양방향) × 1 + NT-Xent × 0.7.

**config 선택이 필요했다** — 저장소가 데이터셋별 config 4개를 주고 **"저장소 기본값" 이 하나가 아니다.**
성능으로 고르면 라벨 기반 선택이라 0절 위반이므로 **데이터 특성만으로** 골랐다:
단일 채널(HAR 9채널 배제) + 원 길이 178 이 창 144 에 가장 가까움 + kernel 8/stride 1 이 짧은 입력용
→ **Epilepsy config**. 상세는 `docs/tstcc_config_choice.md`.

**그 선택의 결과 — 사실상 "2배 스케일 vs permutation" 대조학습이 된다**:
`scaling()` 의 곱셈 인자가 **N(loc=2.0, sigma)** 이고 Epilepsy 의 sigma=0.001 이라 weak view 는
**거의 정확히 2배 고정**이다(실측 배율 중앙값 2.000). `jitter_ratio=0.001` 은 steady e 표준편차
0.041 kg 의 2.4% 로 무시 가능하다. 즉 **두 view 차이가 거의 전부 permutation 에서 온다.**
→ 네 config 중 **증강이 가장 약해 진폭 정보를 가장 많이 보존한다.**

**표현**: 특징맵 평탄화 **2,560차원**(20 × 128). TS-TCC **자신의 분류 헤드와 같은 형태**다.
창 144 에 대한 `features_len = 20` 은 더미 입력으로 **실측**했다(입력 178 에서 config 값 24 가
재현되는 것까지 확인).

**결과**: AUPRC 0.290 (TS2Vec 0.344 보다 아래). 진입 bias +4.4 s 는 양호하다.

**주의 3건**:
1. **퇴화 4/25** (§0.5). 진폭 보존이 강한 표현이라 **진폭 이상 run 에 가장 취약했다** — §6 의
   "진폭 정보를 가장 많이 보존한다" 가 양날이었다.
2. **이 방법만 float64** 로 후단에 넣는다. float32 로는 GMM 적합이 ValueError 로 깨진다
   (2,560차원에서 E[X²]−E[X]² 의 자리수 소실). 모델 선택이 아니라 **수치 정밀도 보정**이다.
3. **런타임 shim 2건** — numpy≥1.24 에서 `permutation()` 이 ragged 리스트로 깨지는 것(난수 소비가
   같은 인덱스 셔플로 대체, 결과 비트 동일), `Trainer()` 가 손실을 반환하지 않아 `model_train` 을
   직접 epoch 루프로 호출(수치적으로 동일).

## 7. 생성/복원 — SimMTM

### 19. `SimMTM`

**무엇인가**: 마스킹된 시계열을 복원하는 사전학습(Dong et al., NeurIPS 2023). 한 시계열에서
마스킹본 3개를 만들어 ① 원본-마스킹본 유사도로 가중치를 학습 ② 그 유사도로 표현을 가중 합산해
원 신호를 복원한다. 손실 = `AutomaticWeightedLoss(대조, 복원 MSE)` — **두 손실의 가중치도 학습한다.**

**config 가 강제된다** — TS-TCC 와 달리 선택의 여지가 없다. Classification 브랜치에 config 2개
(Epilepsy / SleepEEG)가 있는데 **Epilepsy config 는 `CNNoutput_channel` 속성이 없어 사전학습 모델을
만들 수 없다**(`model.py:35`). Epilepsy 는 **target(미세조정) 데이터셋용**이고 사전학습용은 SleepEEG 하나다.

**그리고 config 의 증강 설정이 사전학습에 쓰이지 않는다**: `model_pretrain` 은
`data_transform_masked4cl(data, masking_ratio, lm, positive_nums)` 로 **마스킹만** 한다.
jitter·scaling·permutation 이 경로에 없다 → **TS-TCC 에서 문제였던 증강 세기 축이 여기선 무관하다.**
마스킹 설정은 config 가 아니라 **argparse 기본값**에서 온다 (masking_ratio 0.5, lm 3, positive_nums 3).

**구조 강제값 2개 (실측 확정)**: 입력 144 → conv 출력 (128, **8**) → 표현 **1,024차원**.
`CNNoutput_channel` 을 10 → 8 로, 그리고 **복원 헤드를 `Linear(1280, 178)` → `Linear(1024, 144)` 로
교체**해야 한다 — 원본이 **178 을 하드코딩**하는데 `loss_rb = mse(pred_x, 입력)` 이라 head 출력이
입력 길이와 반드시 같아야 한다.

**표현**: `h` = 평탄화 conv 특징 1,024차원. 저장소의 `target_classifier` 가 쓰는 형태와 같다.

**학습량**: `pretrain_epoch = 10`, `pretrain_lr = 1e-4`. config 의 `lr = 3e-8` 은 **사전학습 경로에서
참조되지 않는다**(`main.py:114` 가 `args.pretrain_lr` 을 쓴다). 통과 횟수 9.99.

**결과**: AUPRC **0.386** — **표현학습 중 CoST 다음 2위**이고 TS2Vec(0.344)·TS-TCC(0.290)보다 높다.
보존률 0.893, 진입 bias +7.3 s.

**주의 2건**:
1. **퇴화 2/25** (fold 2·3 × seed 2) — TS-TCC 와 **동일 조합**이다. 차원이 2.5배 작은데도 같은
   곳에서 터졌으므로 §0.5 의 "원인은 그 run" 설명을 **검증**한다.
2. `CosineAnnealingLR(T_max=pretrain_epoch)` 이라 CoST 와 같이 **손실 곡선이 끝에서 평탄해지는 것은
   수렴의 증거가 아니다.**

## 8. 파운데이션 모델 — MOMENT

### 20. `MOMENT`

**무엇인가**: 시계열 파운데이션 모델(Goswami et al., ICML 2024)의 사전학습 가중치
(`AutonLab/MOMENT-1-small`)를 그대로 쓰고 **추가 학습을 하지 않는다**(zero-shot).
인코더가 고정이라 표현은 fold 와 무관하게 한 번만 계산하고, 학습 fold 에서는 GMM 후단만 적합한다.

**구조가 강제하는 제약 — 임의 선택이 아니다**:

| 제약 | 내용 |
|---|---|
| 입력 길이 512 고정 | run(1275~1300)을 겹치지 않는 512 창으로 자르고 마지막 창은 0 패딩 + `input_mask` |
| 출력이 patch 단위 | `patch_len = stride = 8` → 창당 patch 64개. patch 표현을 그 patch 가 덮는 8개 시점에 복제 |
| 창마다 **RevIN** 정규화 | 제거 불가. **창 단위 평균·스케일이 제거된다** |

**결과**: AUPRC **0.143 — 23종 전체 최하**. 보존률 0.625, AUROC 0.701.
**zero-shot 으로 전혀 전이되지 않는다.**

**유력한 원인**: 창 단위 RevIN 이 **진폭 정보를 지운다.** 본 과제의 구분 정보가 e 의 진폭에 있는데
(미안정 0.209 kg vs steady 0.041 kg) 창마다 스케일을 제거하면 그 정보가 사라진다.
**다만 검증하지 않았으므로 아직 추정이다.**

**부수 사실**: seed 간 결과가 **완전히 동일**하다(표준편차 0.026 은 fold 간 차이이고 같은 fold 안에서는
seed 5개가 같은 값). 학습이 없고 GMM 이 같은 해로 수렴하기 때문이다. 군집 번호만 seed 마다 0/1 이 뒤바뀐다.

**[임의] 값 1개**: `small` vs `base` 모델 크기 선택.

## 9. Ablation — CoST-W144 변형 3종

본문 비교군이 아니라 **"왜 그런가" 를 묻는 실험**이다. 설계 의도는
`research_experiments_plan.md` §8. 창은 전부 **144 고정**이고 나머지 설정도 baseline 과 동일하다.

### 21. `CoST-W144-trend` / 22. `CoST-W144-season` — 표현 성분 분해

**무엇인가**: **재학습 없음.** baseline 체크포인트로 한 번 encode 하고 **슬라이스만 달리해** 같은
트랙 A 후단에 넣는다. CoST 표현은 `cat([trend(160), season(160)])` 이므로 앞 160차원이 추세,
뒤 160차원이 계절이다(`cost.py:334`).

**왜 하나**: **어떤 종류의 정보가 상태 구분에 기여하는지** 알기 위해서다. CoST 가 1위인데 그 성능이
추세(저주파 수렴 거동)에서 오는지 계절(회전 외란 등 주기 성분)에서 오는지 구분되지 않는다.

**연결**: `research_plan.md` 3.1 **D3**(설정값 보정 정상성 — 주기 성분 제거·모델링 후 잔차로 판단).

**결과**: trend AUPRC **0.844**, season **0.821**, 결합(baseline) **0.832**.
**추세만·계절만이 각각 결합과 거의 같다** — 두 성분이 상당 부분 **같은 정보를 담고 있다**는 뜻이고,
**160차원만으로 충분하다.** 계절도 0.821 로 기여하므로 **주기 성분을 제거(residual)하는 설계 D3 는
정보를 버리는 것**이 될 수 있다 → 설계 방향 재검토 근거.

### 23. `CoST-W144-noscaleshift` — scaling/offset 증강 제거

**무엇인가**: CoST 증강 `jitter(shift(scale(x)))` 에서 **scale(곱셈)·shift(덧셈)를 빼고 jitter 만**
남긴 뒤 **재학습**한다. 원본은 수정하지 않고 `cost.PretrainDataset` 을 런타임 서브클래스로 바꿔치기한다.

**왜 하나**: **실험별 수준·크기 차이에 대한 학습이 일반화에 기여했는지** 검토한다.
`scale`·`shift` 는 "신호의 크기와 오프셋이 달라도 같은 상태" 라고 가르치는데, **본 과제의 구분 정보는
e 의 진폭 자체**에 있다. 문제의 크기: sigma = 0.5 는 steady 구간 e 표준편차 0.041 kg 의 **12배**이고,
`scale` 은 약 2.3% 확률로 **부호를 뒤집는다.**

**jitter 를 남긴 이유**: CoST 는 두 view 가 증강으로만 달라지므로 증강을 전부 끄면 양성 쌍이 같아져
**대조 과제가 자명해진다**(`research_experiments_plan.md` §8.4).

**연결**: `research_plan.md` 3.1 **D2**(도메인 불변성 정의 증강 — 설정값 수준에는 불변, 오차 진폭은 보존).

**결과 — 모든 종합 지표가 좋아진다.** 23종 전체 1위다:

| | AUROC | AUPRC | F1(ns) | 오염률 | 진입 MAE |
|---|---|---|---|---|---|
| baseline `CoST-W144` | 0.964 | 0.832 | 0.902 | 0.005 | 5.8 s |
| **`-noscaleshift`** | **0.978** | **0.853** | **0.913** | 0.003 | **5.1 s** |

**D2 가설의 직접 증거**다 — 그 증강이 구분 정보를 지우고 있었다.
