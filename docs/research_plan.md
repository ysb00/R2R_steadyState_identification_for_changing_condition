# Research Plan (v0.2)

**주제**: 롤투롤 장력 신호의 도메인 특성을 반영한 정상성 기반 대조 표현학습으로,
라벨 없이 미학습 장비 조건에서 정상상태(steady state) 구간을 식별하는 방법

- 작성일: 2026-10-20 / 상태: 설계안 (문헌 검토·탐색적 분석 전, 가정 검증 필요)
- 본 연구의 "이상"은 제품 이상이 아니라 **non-steady state(장비 신호 미안정)** 를 뜻한다.

## 0. 연구 전제
- 정상/비정상의 **위치를 전혀 모르는 상태**에서 적용 가능해야 한다.
- 사용 금지: `Trigger 4` 라벨(최종 평가에만 사용), "run 후반 = 정상"·"run 초반 = 비정상" 같은 위치 가정.
- 사용 가능: 장력 신호, 장비 설정값(장비 정보), 정상상태의 일반적 정의(정상성·추세 없음·설정값 추종).
- 하이퍼파라미터 선택에도 라벨을 사용하지 않는다.

## 1. 연구 동기
1. 이상(non-steady) 탐지·품질 모델 학습에는 steady 데이터 선별이 필요하나, 현재는 전문가 수작업이다.
2. 장력·속도 레시피가 바뀌면 신호 수준·과도 형태·안정화 시간(0–52 s)이 달라지며, 모든 조건을 실험·라벨링할 수 없다.
3. 통계 기반 SSI는 조건별 임계값 재튜닝이 필요하다.
   - Cao & Rhinehart (1995), J. Process Control 5(6):363–374. https://doi.org/10.1016/0959-1524(95)00009-F
   - Kelly & Hedengren (2013), J. Process Control 23(3):326–331. https://scholarsarchive.byu.edu/facpub/1713 (DOI 미확인)

## 2. 미해결 문제 (가설 — 문헌 검토로 검증 필요)
| # | 미해결 문제 | 기존 연구 상황 |
|---|---|---|
| G1 | 미학습 장비 조건에서의 SSI 적용성 | 통계 SSI는 조건별 재튜닝; 미학습 조건에서 ground truth로 평가한 사례 미확인 |
| G2 | 자기지도 표현이 "정상상태"를 담고, 조건 변화에도 유지되는가 | 시계열 SSL은 주로 분류·예측 벤치마크로 평가 |
| G3 | 한 상태가 압도적인 데이터(steady 86%)에서 대조학습의 거짓 음성 | TNC(PU 가중), SoftCLT(연속 가중)가 부분 대응, 정상성 기준 가중은 미확인 |
| G4 | 연속적·구조적 조건 정보(설정값)를 활용한 일반화 | 시계열 도메인 일반화는 주로 범주형 도메인 가정 |

데이터 근거: steady 구간 잡음은 조건 간 유사(std 0.033–0.065)하나, 과도 처짐은 속도에 따라 −0.23→−0.46 kg,
속도 150에서 steady 편차가 모든 T·R 조건에서 체계적으로 증가(0.044–0.058 vs ≈0.038).

## 3. 방법론 위치와 비교군
### 3.1 방법론 카테고리
- 자기지도 표현학습의 6개 계열(생성/복원, 대조, 비대조 공동 임베딩, JEPA, 적대적, 프리텍스트) 중
  **대조학습 — 시간 이웃·연속 가중치 하위 계열**에 속한다.
  (시계열 SSL 분류: Zhang et al., IEEE TPAMI 46(10), 2024, https://arxiv.org/abs/2306.10125)
- 기여 포인트: 거짓 음성(G3)을 피할 위험이 아니라 **정상성 기준 가중치로 해결할 문제**로 다룬다.

### 3.2 제안 방법 구성 (초안)
1. 양성 쌍: 같은 구간의 도메인 기반 변형, 시간 이웃 — 라벨·위치 정보 불필요, 정상/비정상 구간 모두 사용
2. 음성 쌍: 두 구간의 (조건 정규화된) 정상성 통계 차이에 따른 연속 가중치
3. 도메인 지식 반영

   | 위치 | 내용 | 상태 |
   |---|---|---|
   | (a) 입력 정규화 | e = T1 − 설정값 (또는 비율) | 데이터로 확인 |
   | (b) 시간축 정규화 | 시간 → 필름 이동 거리 | 가설; 안정화 시간이 U자형이라 일부 불일치, EDA로 검증 |
   | (c) 도메인 기반 증강 | 설정값 비율 크기 변화, 롤 회전 주기 성분, 속도 의존 time-warp | 가설; 주파수 분석 필요 |
   | (d) 신호 분해 구조 | 설정값 + 과도 응답 + 주기 + 잡음 분해, 과도 성분 크기를 판단 근거로 | 처짐은 확인, 응답 형태 미확인 |
   | (e) 도메인 허용오차 | 정상 기준을 현장 허용오차로 정의 | 사용자 정보 필요 |
4. 상태 분할: 학습된 표현 위 HMM 또는 TICC, 정상 상태는 정의(추세≈0, 설정값 추종)로 지정

### 3.3 비교군

#### 비교 ① 계열 비교 — 대조학습 선택 근거
원칙: 계열별 대표 1–2개를 **본 데이터로 처음부터, 동일 인코더 크기로 학습**하여 차이가 학습 방식에서만 나오게 한다.

| 계열 | 대표 방법 (연도) | 비교 목적 |
|---|---|---|
| 생성/복원 | TimeMAE(2023)\* 또는 SimMTM(2023) | 쌍 정의 없는 복원 방식 대비 |
| 비대조 공동 임베딩 | VICReg식 시계열 적용(원 논문 2022)\*, 또는 확인되는 시계열 방법 | 음성 쌍을 쓰지 않는 방식 대비 — "거짓 음성 회피" vs "가중치로 교정" 직접 검증 |
| JEPA | TS-JEPA(2025)\* | 표현 공간 예측 방식 대비 |
| 프리텍스트 | T-Rep(2024) | 대리 과제 방식 대비 |
| 적대적 | 제외 | 작은 데이터에서 학습 불안정, 최근 표현학습에서 비중 낮음 |
| 참고(별도) | MOMENT(2024, 추가 학습 없음) | 계열 비교와 분리: "대규모 사전학습으로 충분한가" 확인 |

#### 비교 ② 대조학습 내부 비교 — 양성/음성 쌍 정의 방식별

| 쌍 정의 방식 | 대표 방법 (연도) | 확인할 질문 |
|---|---|---|
| 예측 기반 대조 | CPC(2018)\* | 고전적 기준선 |
| 데이터 증강 기반 | TS-TCC(2021) | 변형만으로 양성 정의가 충분한가 |
| 시간 이웃 기반 | TNC(2021) | 정상성 검정 기반 이웃 정의의 효과 |
| 시점 단위·다중 해상도 | TS2Vec(2022) | 시점 단위 표현이 진입 시점 검출에 유리한가 |
| 연속 가중치 | SoftCLT(2024, TS2Vec에 plug-in) | **제안 방법과 가장 가까운 비교**: 시간 간격 기준 vs 정상성 기준 가중치 |
| 성분 분해 | CoST(2022) | 추세 성분 분리 효과 — 도메인 지식 (d)와 비교 |
| 주파수 영역 | TF-C(2022) | 주파수 정보 효과 — 속도 150 현상 관련 |
| 혼합(대조+복원) | TimesURL(2024) | 복원 과제 추가 효과 |

\* TimeMAE, VICReg, TS-JEPA, CPC: 문헌 검토 단계에서 출판 정보와 코드 공개 여부를 확인해 최종 포함 여부 결정.

#### 비교 ③ 표현학습 외 기준선과 성능 범위
| 구분 | 방법 (연도) |
|---|---|
| 통계 SSD | R-test(1995), 웨이블릿 SSD(2003), Kelly–Hedengren(2013) |
| 변화점 검출 | PELT(2012), BOCPD(2007) |
| 성능 범위 | 상한: 동일 인코더 전문가 라벨 지도학습 / 하한: 단순 임계값 |
| 검토 후 결정 | 최근 정상상태 검출 연구 arXiv 2506.04204(2025), arXiv 2608.24194(2026) |

공정성: 동일 입력, 동일 분할, 동일 인코더 크기·후단, 모든 방법 라벨 없는 하이퍼파라미터 선택.

## 4. 실험 설정
- 데이터: 210 runs (Film Tension 5 × ReWinder 6 × Speed 7), 분할은 항상 run/조건 단위
- E1 (주 실험): Tension leave-one-level-out 5-fold
- E2 (내삽): 격자 내부 조건 제외 (예: T5, V125)
- E3 (외삽): 격자 끝 조건 제외 (예: T7, V175–200)
- E4 (특이 조건): 속도 150 제외
- Ambiguous(2): 주 평가 제외, 보조 평가에서 양쪽 모두 정답 처리
- 지표: 오염률(최우선), 보존률, steady 진입 시점 오차(s), AUROC/AUPRC(non-steady = positive), F1, 조건별 heatmap
- 통계: seed 5회 평균 ± 표준편차, run 단위 Wilcoxon
- Ablation: 도메인 지식 (a)–(e) 각각, window 길이, 가중치 방식, `Web Current Speed` 포함 여부
