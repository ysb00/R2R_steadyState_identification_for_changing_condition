# Research Plan (v0.3)

**주제**: 롤투롤 장력 신호의 도메인 특성을 반영한 자기지도 표현학습으로,
라벨 없이 미학습 장비 조건에서 정상상태(steady state) 구간을 식별하는 방법

- 작성일: 2026-10-20 (중간 점검 반영) / 상태: 설계안 — 1차 문헌 검토 완료, 실험 전
- 본 연구의 "이상"은 제품 이상이 아니라 **non-steady state(장비 신호 미안정)** 를 뜻한다.

---

## 0. 연구 전제
- 정상/비정상의 **위치를 전혀 모르는 상태**에서 적용 가능해야 한다.
- 사용 금지: `Trigger 4` 라벨(최종 평가에만 사용), "run 후반 = 정상"·"run 초반 = 비정상" 같은 위치 가정.
- 사용 가능: 장력 신호, 장비 설정값(장비 정보), 정상상태의 일반적 정의(정상성·추세 없음·설정값 추종).
- 하이퍼파라미터 선택에도 라벨을 사용하지 않는다.

## 2. 연구 동기
1. 이상(non-steady) 탐지·품질 모델 학습에는 steady 데이터 선별이 필요하나, 현재는 전문가 수작업이다.
2. 장력·속도 레시피가 바뀌면 신호 수준·과도 형태·안정화 시간이 달라지며, 모든 조건을 실험·라벨링할 수 없다.
3. 통계 기반 SSI는 조건별 임계값 재튜닝이 필요하다.
   - Cao & Rhinehart (1995), J. Process Control 5(6):363–374. https://doi.org/10.1016/0959-1524(95)00009-F
   - Kelly & Hedengren (2013), J. Process Control 23(3):326–331. https://scholarsarchive.byu.edu/facpub/1713 (DOI 미확인)

### 3.1 대조학습을 사용할 경우의 차별점 — R2R 장력 신호 특성 기반

차별점은 "미학습 운전조건 검증" 하나가 아니라, R2R 장력 신호가 기존 연구 데이터(생체신호·동작·UCR/UEA)와
성질이 달라 **기존 대조학습의 설계 가정이 깨지는 지점**에서도 나온다.

#### (1) 새로 확인한 신호 특성 (1.2절 수치 참조)
| 특성 | 의미 |
|---|---|
| steady 구간 주기 성분, 주파수 ∝ 속도 | 주파수 ÷ 속도 ≈ 일정 → **회전체 1회전마다 반복되는 외란**(롤 편심 등). **검증 완료** — 라벨 없이 210 run 전체 스펙트럼으로 재측정한 결과 환산 둘레 **783.5 ± 13.1 mm (지름 249.4 mm)**, 속도 5수준에서 표준편차 1 mm 미만. **출처는 리와인더 롤이 아니다** — 리와인더 지름이 143→284 mm 로 2배 변해도 주파수가 0.064–0.065 Hz 로 고정이다(`corr(f_peak, 1/D) = −0.233`). **지름 ≈ 249 mm 의 고정 지름 회전체**이며 어느 롤러인지는 미확인. 상세: `docs/periodic_disturbance.md` |
| steady 잡음 자기상관 높음 | 잡음 독립 가정을 쓰는 기법(R-test 등)의 전제가 깨짐 |
| 측정 해상도 0.01 kg | steady 변동이 측정 단위 4칸 남짓 |
| 미안정/steady 진폭 차이 | 구분 정보가 **진폭 자체**에 있음 |

#### (2) 기존 연구 데이터와의 비교
| 성질 | 기존 연구 데이터 (HAR, 뇌파, 심전도, UCR/UEA) | R2R 장력 신호 |
|---|---|---|
| 신호 기준점 | 정해진 목표값 없음 | 폐루프 제어로 **알려진 설정값을 추종** → 정상 여부를 설정값 기준으로 정의 가능 |
| 상태 구조 | 상태가 번갈아 나타나거나(동작) 주기적 반복(심전도) | **과도 → 정상으로 한 방향 수렴**, 정상이 대부분(86%) |
| 구분 정보 위치 | 파형 모양·패턴 | **진폭(오차 크기)과 저주파 추세** |
| 조건 차이 | 사람·기기 차이, 원인 미관측 | **알려진 물리량(설정값)이 동특성 변화** (처짐 크기, 주기 주파수) |
| 정상 상태 내부 구조 | 해당 없음 | **속도 비례 주기 외란**이 정상 상태에도 존재 |

#### (3) 기존 설계 가정이 깨지는 지점 → 차별점 후보
| # | 기존 설계 | R2R에서의 문제 | 차별점이 되는 설계 |
|---|---|---|---|
| D1 | 고정 길이 구간으로 정상성 판단 (StatioCL의 ADF, TNC 이웃 범위) | 속도 50에서 주기 약 17 s → 7 s 구간 안에서는 steady의 느린 진동이 "추세"로 보여 비정상으로 오판; 속도 200은 주기 약 4 s로 판단이 달라짐 | **주기 반영 구간 길이·이웃 범위**: 속도에 따른 구간 길이 조정 또는 필름 이동 거리 기준 재샘플링 — 4.1 (b)를 안정화 시간이 아닌 주기 성분 근거로 재정립 |
| D2 | 일반 증강 (scaling, jitter) | scaling은 오차 진폭(구분 정보)을 변경; steady 변동이 측정 단위 4칸 수준이라 jitter는 경계를 흐림 | **도메인 불변성 정의 증강**: 설정값 수준에는 불변, 오차 진폭은 보존, 주기 성분의 위상·주파수 변화는 같은 상태로 취급 |
| D3 | 조건과 무관한 고정 정상성 기준 | 속도 150 분산 증가, 속도별 주기 주파수 → 같은 정상이라도 조건마다 통계 상이 | **설정값 보정 정상성**: 주기 성분 제거·모델링 후 잔차로 정상성 판단, 미학습 조건에도 적용 |
| D4 | 일반적 거짓 음성 완화 (연속 가중치, 군집) | 한 방향 수렴·누적 상태(86%)로 거짓 음성 구조가 다름 | 정상 압도 구조를 이용한 쌍 구성 — 기존 방법과의 차이를 실험으로 입증 필요 |
| D5 | 같은 분포 안 평가 | – | **미학습 운전조건 평가** (E1–E4) |
| D6 | 기록 단위 분류 평가 | – | **시점 단위 정상 진입 시점 검출** 평가 |

#### (3-1) 1차 비교군 실행으로 확인된 것 — **기존 표현학습에는 상태 구분 과제가 없다** (2026-10-26)

위 (3)은 문헌 검토에 기반한 **가설**이었다. A 실험(비교군 8개 / 변형 23종) 실행 후 **실측 근거**가 모였다.

##### ① 평가 파이프라인이 고정돼 있어, 각 방법이 기여하는 것은 '시점별 벡터' 하나뿐이다

```
시점별 d차원 벡터  ->  StandardScaler(학습 fold)  ->  2군집 diag GMM(학습 fold)
                   ->  |e 평균| 작은 군집 = steady  ->  사후확률 >= 0.5 이면 steady
```

23종 중 **21종이 이 후단을 공유**한다 (예외는 R-test 원 논문판 2종 — 고정 임계값 2.5/0.9 +
히스테리시스로 GMM 을 쓰지 않는다. 그래서 보정판 2종을 추가해 같은 후단에 넣었다).
`d` 는 **1 ~ 2,560** 까지 2,560배 범위다.

따라서 비교하는 것은 **"어떤 임베딩이 steady/non-steady 를 2개의 축정렬 가우시안으로 갈라놓는가"**
이다. 임베딩이 두 상태를 분리해도 **축정렬(diag)·가우시안 형태가 아니면** 후단이 찾지 못한다.

##### ② 표현학습 7종 전부 상태 구분을 목적함수에 두지 않는다

| 방법 | 학습 목표 | 상태 구분 과제 |
|---|---|---|
| TS2Vec | 계층적 대조 (증강·시점 양성쌍) | ❌ |
| CoST | 추세/계절 분기 대조 (시간·주파수 영역) | ❌ |
| SoftCLT | TS2Vec + soft label (DTW 거리 / 시간 거리) | ❌ |
| TS-TCC | Temporal contrasting(과거→미래) + NT-Xent | ❌ |
| SimMTM | 마스킹 복원 MSE + 대조 (가중치도 학습) | ❌ |
| MOMENT | 다른 데이터로 사전학습, zero-shot | ❌ |
| LaST | 예측 MAE + ELBO + MLBO − MUBO | ❌ |
| **R-test** ×4 | 분산비 R — **steady 여부를 직접 판정하도록 설계** | ⭕ |
| **MovStd-Slope** ×4 | std·기울기 — **"조용하고 흐르지 않으면 steady" 정의를 직접 구현** | ⭕ |

**표현학습 7종은 범용 시계열 표현을 배우고, 상태 구분은 우리가 붙인 GMM 후단이 한다.**
통계 SSD 2종만 설계 목적 자체가 steady 판정이다.

파이프라인 전체에서 상태에 대한 도메인 지식이 들어오는 곳은 **딱 한 곳**, `|e 평균| 작은 군집 =
steady` 규칙뿐이다. **표현을 만드는 단계에는 상태 지식이 전혀 들어가지 않는다.**

| MOMENT | 512 | ❌ | 0.143 ± 0.049 |

**2차원 통계 기준선이 범용 표현 7종 중 5종을 이긴다.** 상태 구분 목적함수가 없는 표현은
"steady 를 가르는 축" 을 배울 이유가 없고, 그 축은 우연히 포함될 때만 작동한다.

##### ④ 더 강한 증거 — 범용 목적함수가 구분 정보를 **적극적으로 지운다**

| 관찰 | 수치 | 뜻 |
|---|---|---|
| **TS2Vec: 학습할수록 나빠진다** | 최종손실 ↔ AUPRC 상관 **+0.61**. 손실이 거의 안 떨어진 11회의 AUPRC 0.438 vs 떨어진 14회 0.270 | 대조 목적함수를 더 최적화할수록 steady 분리가 나빠진다. 난수 초기화 인코더는 입력의 무작위 사영이라 **진폭 정보를 보존**하는데, 학습이 진행되면 증강 불변 특징을 배우며 그 진폭을 버린다 |
| **CoST: 증강을 빼면 좋아진다** | scaling/shift 제거 후 AUPRC 0.832 → **0.853**, AUROC 0.964 → 0.978, 진입 MAE 5.8 → 5.1 s | `scale`·`shift` 는 "크기·오프셋이 달라도 같은 상태" 라고 가르치는데, 본 과제의 구분 정보는 **e 의 진폭 자체**다. sigma = 0.5 는 steady e 표준편차 0.041 kg 의 **12배**이고 약 2.3% 확률로 **부호를 뒤집는다** |
| **CoST: 추세만·계절만이 결합과 거의 같다** | 0.844 / 0.821 vs 결합 0.832 (각 160차원) | 두 성분이 상당 부분 같은 정보를 담는다. 320차원 중 절반이 중복이다 |
| **학습량과 성능이 역순** | 데이터 통과 3.17회(CoST-W144) AUPRC 0.832 ↔ 38.1회(TS-TCC) 0.290. 창 간에서는 완벽한 역순 | 같은 방향의 관찰이 방법·설정을 가로질러 재현된다 |

**이 네 관찰이 D2 가설의 직접 근거다.** 가설이 아니라 측정이다.

##### ⑤ 2군집 가정에도 한계가 확인됐다

`N_GMM_COMPONENTS = 2` 는 **[계획]** 값으로 "상태가 2개" 와 "가장 강한 분리축이 상태축" 을 함께
가정한다. 두 가정이 모두 깨진 사례가 나왔다:

- **TS-TCC 4/25, SimMTM 2/25 에서 GMM 이 `steady vs non-steady` 가 아니라
  `이상치 190개 vs 나머지 21.4만` 으로 갈랐다.** AUROC 가 정확히 0.500 이 된다.
  원인은 진폭 이상 run `T3_R2_V200` 단독이다 (`hyperparameters.md` §11 문제 11).
- 2군집 가정이 걸리는 곳은 **모델이 아니라 지표**다. GMM 은 학습 fold 전체에 두 상태가 있으면
  되고 그건 성립한다. 그러나 **210 run 중 26개(12.4%)가 non-steady 시점 0개**여서
  **AUROC·AUPRC·F1(ns) 가 184/210 run 에서만** 계산된다.

##### ⑥ 차별점으로 이어지는 결론

1. 기존 표현학습은 **상태 구분을 목적함수에 두지 않으므로**, steady 판별에 필요한 축
   (e 의 진폭·수렴 거동)을 보존할 보장이 없다 — ②③.
2. 그리고 범용 목적함수가 그 축을 **적극적으로 지운다** — ④. 증강 불변성(D2)과
   학습량(§13.2 교란)이 모두 같은 방향을 가리킨다.
3. 따라서 **상태 구분을 목적함수에 넣거나, 상태를 정의하는 정보(진폭·수렴 순서)를 보존하는
   증강 설계**가 차별점이 된다 — D2 를 가설에서 **측정된 사실**로 승격할 수 있다.
4. 후단의 **2군집·축정렬 가정** 자체도 재검토 대상이다 — ⑤.

#### (4) 차별점 주장에 필요한 것
- **기존 설계가 실제로 깨짐을 실험으로 입증**: 고정 구간 길이·ADF 기준(StatioCL 방식)이 저속 조건에서 steady를 비정상으로 오판하는지, 일반 증강이 성능을 떨어뜨리는지 ablation으로 제시 → D1–D3가 "필요해서 한 설계"라는 근거.
- **일반화 논리**: 설정값 추종과 회전 동기 외란은 회전체를 쓰는 폐루프 제어 공정 일반의 성질일 가능성(추정, 문헌 확인 필요) → "R2R 한 사례" 비판 완화.
- **주기 성분의 정체 확인**: 원본 롤 지름 열과 비교해 회전 주기와 일치하는지 확인 (교란 확인용 열 사용 승인 필요).

## 4. 방법론 위치

자기지도 표현학습 6개 계열(생성/복원, 대조, 비대조 공동 임베딩, JEPA, 적대적, 프리텍스트) 중 주 계열을 선택한다

## 6. 실험 설정
- 분할은 항상 run/조건 단위
- E1 (주 실험): Tension leave-one-level-out 5-fold
- E2 (내삽): 격자 내부 조건 제외 (예: T5, V125)
- E3 (외삽): 격자 끝 조건 제외 (예: T7, V175–200)

- 지표: 오염률(최우선), 보존률, steady 진입 시점 오차(s), AUROC/AUPRC(non-steady = positive), F1, 조건별 heatmap

- Ablation: 도메인 지식 (a)–(e), window 길이, 가중치 방식, `Web Current Speed` 포함 여부

### 9.2 C 실험 완료 — **최종 목표는 성립한다** (2026-10-27)

**저속 50/75/100/125 (120 run) 만 학습하고 미학습 고속 150/175/200 (90 run) 으로 테스트**하는
C 실험을 23종 x 8 fold x 5 seed 로 실행했다 (`hyperparameters.md` §13.0, `worklog.md` 2026-10-27).

| 방법 | 오염률 | 보존률 | AUROC | **AUPRC(ns)** | 진입 MAE (s) |
|---|---|---|---|---|---|
| **CoST-W144** | 0.001 | 0.992 | 0.989 | **0.907** | **4.2** |
| MovStd-Slope-fixed | 0.005 | 0.887 | 0.975 | 0.847 | 5.1 |
| SimMTM | 0.025 | 0.990 | 0.854 | 0.648 | 8.0 |
| R-test-decimated-calibrated | 0.022 | 0.918 | 0.862 | 0.591 | 19.1 |
| TS2Vec | 0.013 | 0.743 | 0.832 | 0.290 | 11.7 |
| SoftCLT-fs-rule1b | 0.000 | 0.622 | 0.811 | 0.204 | 45.6 |
| TS-TCC | 0.003 | 0.471 | 0.727 | 0.146 | 23.9 |
| MOMENT | 0.053 | 0.588 | 0.621 | 0.114 | 13.5 |

**A 실험과 순위 구조가 같다** — CoST 1위, **2차원 통계 기준선이 2위**로 표현학습 5종을 이긴다.
3.1 (3-1) ③ 의 관찰("상태 구분 목적함수가 없는 표현은 그 축을 보존할 보장이 없다")이
**조건 축을 장력에서 속도로 바꿔도 재현된다.** 차별점 D2 의 근거가 한 축 더 늘었다.

**새로 드러난 것 2가지**

1. **미학습 고속이 저속 CV 보다 오히려 쉽다** — 23종 중 18종에서 `final_test` 가 `cv_T` 보다 높다
   (평균 +0.079). 1.2 절의 **"미안정 구간 처짐이 속도에 비례해 커진다(-0.23 -> -0.46 kg)"** 와
   방향이 맞는다. 속도 외삽의 어려움보다 **신호 대비 증가 효과가 컸다.**
   단 학습 run 이 96 -> 120 으로 달라 **학습량 교란이 섞여 있다** (§13.0).
2. **속도 150 문제가 최종 테스트에서 재현됐고, 방법에 따라 영향이 갈린다** — `MovStd-Slope-fixed`
   보존률이 속도 150 에서 0.710 인데 175·200 에서는 0.971·0.984 다. 반면 **CoST·SimMTM 은
   세 속도 모두 0.98 이상**으로 영향이 없다. L9(속도 150 원인 미상)가 **데이터만의 문제가 아니라
   방법이 다룰 수 있는 문제**임을 보여준다.

**L2(조건 범위 좁음) 완화**: "외삽 1~2단계" 였던 한계가 C 실험에서 **3수준 외삽**(125 -> 200)으로
넓어졌다. 다만 여전히 장비 1대·필름 1종이므로 L1 은 그대로다.
