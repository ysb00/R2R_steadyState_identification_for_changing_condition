# Research Plan (v0.3)

**주제**: 롤투롤 장력 신호의 도메인 특성을 반영한 자기지도 표현학습으로,
라벨 없이 미학습 장비 조건에서 정상상태(steady state) 구간을 식별하는 방법

- 작성일: 2026-10-20 (중간 점검 반영) / 상태: 설계안 — 1차 문헌 검토 완료, 실험 전
- 본 연구의 "이상"은 제품 이상이 아니라 **non-steady state(장비 신호 미안정)** 를 뜻한다.

---

## 0. 연구 전제
- 정상/비정상의 **위치를 전혀 모르는 상태**에서 적용 가능해야 한다.
- 사용 금지: `Trigger 4` 라벨(최종 평가에만 사용), "run 후반 = 정상"·"run 초반 = 비정상" 같은 위치 가정.
- 사용 가능: 장력 신호, 장비 설정값(장비 정보), 정상상태의 일반적 정의(정상성·추세 없음·설정값 추종).
- 하이퍼파라미터 선택에도 라벨을 사용하지 않는다.

### 1.1 사용 컬럼 (원본 이름)
| 컬럼 | 역할 |
|---|---|
| `Film Tension #1 (kg)` | 분석 대상 실측 신호 |
| `Film-Tension Setting Value (kg)`, `ReWinder-Tension Setting Value (kg)`, `Web Speed setting value (mm/sec)` | 장비 설정값 (실시간 신호 아님) |
| `Trigger 4` | expert 수동 라벨: 0 = 미안정, 1 = steady state, 2 = ambiguous — **최종 평가에만 사용** |
| `Web Current Speed (mm/sec)` | 실측 속도 — 사용 여부 미정 (ablation 후보) |
| 추가: `run_id`, `k` | run 식별자, run 내 샘플 순번 |

### 1.2 데이터에서 확인한 사실
| 항목 | 값 |
|---|---|
| 라벨 비율 | steady 85.8%, 미안정 7.6%, ambiguous 6.6% |
| 첫 steady 도달 시간 | 평균 19.5 s, 0–52 s (근사값); 미안정 구간 없는 run 26개 |
| steady 진입 후 재불안정 | 3 runs (`T3_R7_V200`, `T5_R6_V50`, `T6_R7_V50`) |
| steady 구간 장력 편차 | 조건 간 유사(0.033–0.065 kg), **단 속도 150에서 모든 장력 조건에 걸쳐 체계적 증가** (0.044–0.058 vs ≈0.038) |
| 미안정 구간 장력 처짐 | 속도 증가에 따라 증가 (−0.23 → −0.46 kg) |

## 2. 연구 동기
1. 이상(non-steady) 탐지·품질 모델 학습에는 steady 데이터 선별이 필요하나, 현재는 전문가 수작업이다.
2. 장력·속도 레시피가 바뀌면 신호 수준·과도 형태·안정화 시간이 달라지며, 모든 조건을 실험·라벨링할 수 없다.
3. 통계 기반 SSI는 조건별 임계값 재튜닝이 필요하다.
   - Cao & Rhinehart (1995), J. Process Control 5(6):363–374. https://doi.org/10.1016/0959-1524(95)00009-F
   - Kelly & Hedengren (2013), J. Process Control 23(3):326–331. https://scholarsarchive.byu.edu/facpub/1713 (DOI 미확인)

## 3. 미해결 문제 (1차 문헌 검토 반영)

| # | 미해결 문제 | 판정 | 근거 요약 |
|---|---|---|---|
| G1 | 미학습 장비 조건에서의 SSI 적용성 | 미해결로 보임 | 최근 SSD 연구는 통계·커널 기반, 조건 일반화 미다룸 (KB-KSSD 2025, arXiv 2506.04204; Heinrichs 2026, arXiv 2608.24194); R2R ML 연구는 제어·디지털 트윈 중심 |
| G2 | 자기지도 표현이 "정상상태"를 담고 조건 변화에도 유지되는가 | 미해결로 보임 | 인접 연구는 자기지도 변화점 검출(TS-CP2), 구간 분할(ClaSP 계열) |
| G3 | steady가 압도적인 데이터에서 대조학습의 거짓 음성 | **상당 부분 기존 연구 존재** | StatioCL(2024), SoftCLT(2024), AdaTS(2025), MHCCL(2023), Jin et al.(arXiv 2312.11939) |
| G4 | 연속적 조건 정보(설정값) 활용 일반화 | 지도학습 연구는 존재, **라벨 없는 경우 미확인** | Koodos(NeurIPS 2024, 시간 도메인), 운전조건 지표 기반 고장진단 DG(MDPI — 목록 제외) |

**재정의한 차별점 (잠정)**: ① 시점 단위 steady/non-steady 구간 분할 문제 ② 설정값 보정 정상성과 R2R 장력 도메인 구조 반영 ③ 미학습 운전조건에서 라벨 없이 평가.
※ 문헌 검토는 웹 검색 기반이며, 논문 본문 확인과 인용 추적은 미완료.

## 4. 방법론 위치

자기지도 표현학습 6개 계열(생성/복원, 대조, 비대조 공동 임베딩, JEPA, 적대적, 프리텍스트) 중 주 계열을 선택한다
(시계열 SSL 분류: Zhang et al., IEEE TPAMI 46(10), 2024, https://arxiv.org/abs/2306.10125).

| 후보 | 장점 | 어려운 점 | 가까운 선행 연구 |
|---|---|---|---|
| 대조학습 | 동작 기반 풍부, "다르다" 정보 활용 | 거짓 음성 보정, 기존 연구와의 차별성 증명 | StatioCL, SoftCLT, AdaTS, CaTT, ShiFT, Di-COT, REBAR, MHCCL |
| 비대조 | 거짓 음성 문제 구조적으로 없음, 시계열에서 덜 탐색됨 | 표현 붕괴, steady/과도 구분력, 설계를 처음부터 | DEAPS(IJCAI 2024, 코드 미확인) |

- 양성 쌍은 정상/비정상 구간 모두에서, 라벨이 아닌 신호 성질(같은 구간의 변형, 시간 이웃, 통계 유사도)로 정의한다. steady 구간만 골라 양성으로 쓰는 것은 라벨 사용과 같으므로 금지.

### 4.1 도메인 지식 반영 후보
| 위치 | 내용 | 상태 |
|---|---|---|
| (a) 입력 정규화 | e = T1 − 설정값 (또는 비율) | 데이터로 확인 |
| (b) 시간축 정규화 | 시간 → 필름 이동 거리 | 가설; 안정화 시간이 U자형이라 일부 불일치 |
| (c) 도메인 기반 증강 | 설정값 비율 크기 변화, 롤 회전 주기 성분, 속도 의존 time-warp | 가설; 주파수 분석 필요 |
| (d) 신호 분해 구조 | 설정값 + 과도 응답 + 주기 + 잡음 분해 | 처짐은 확인, 응답 형태 미확인 |
| (e) 도메인 허용오차 | 정상 기준을 현장 허용오차로 정의 | 사용자 정보 필요 |

## 6. 실험 설정
- 분할은 항상 run/조건 단위
- E1 (주 실험): Tension leave-one-level-out 5-fold
- E2 (내삽): 격자 내부 조건 제외 (예: T5, V125)
- E3 (외삽): 격자 끝 조건 제외 (예: T7, V175–200)
- E4 (특이 조건): 속도 150 제외
- Ambiguous(2): 주 평가 제외, 보조 평가에서 양쪽 모두 정답 처리
- 지표: 오염률(최우선), 보존률, steady 진입 시점 오차(s), AUROC/AUPRC(non-steady = positive), F1, 조건별 heatmap
- 통계: seed 5회 평균 ± 표준편차, run 단위 Wilcoxon
- Ablation: 도메인 지식 (a)–(e), window 길이, 가중치 방식, `Web Current Speed` 포함 여부
